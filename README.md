## Railway

1. Deploy from this repo
2. Variables from `sample.env`
3. Worker: `python3 -m TanuMusic`
4. Cookies: `TanuMusic/cookies/cookies.txt`
5. Log group: bot + assistant admin

## Local

```bash
pip install -r requirements.txt
cp sample.env .env
python3 -m TanuMusic
```
