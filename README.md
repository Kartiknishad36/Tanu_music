    ─「 ᴅᴇᴩʟᴏʏ ᴏɴ ʀᴀɪʟᴡᴀʏ 」─
</h3>

1. Fork / use this repo: [Kartiknishad36/Tanu_music](https://github.com/Kartiknishad36/Tanu_music)
2. Open [Railway](https://railway.app) → **New Project** → **Deploy from GitHub**
3. Select **Tanu_music**
4. Add variables from `sample.env` (API_ID, API_HASH, BOT_TOKEN, STRING_SESSION, MONGO_DB_URI, OWNER_ID, LOGGER_ID …)
5. Start command / worker: `python3 -m TanuMusic`
6. Put YouTube cookies in `TanuMusic/cookies/cookies.txt` (file, not public URL)

```bash
git clone https://github.com/Kartiknishad36/Tanu_music.git
cd Tanu_music
pip install -r requirements.txt
cp sample.env .env
nano .env
# fill API_ID, API_HASH, BOT_TOKEN, STRING_SESSION, MONGO_DB_URI, OWNER_ID, LOGGER_ID
# cookies → TanuMusic/cookies/cookies.txt
python3 -m TanuMusic
```

**tmux (optional):**
```bash
sudo apt install tmux && tmux
python3 -m TanuMusic
# detach: Ctrl+b then d
```
